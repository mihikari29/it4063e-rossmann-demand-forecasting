## Bundle contract

The [release contract](../../docs/PUBLIC_DEMO_RELEASE_CONTRACT.md) owns exact schemas and content.
Release ID is `rossmann-course-demo-synthetic-v1`, schema `1.0.0`, profile/evidence kind
`controlled_synthetic_demo`, seed **4063**. Fixtures contain Stores 101/202/303, three saved
May 22/June 5/June 19 origins, H14 paths, synthetic Fit A/B pairings for the June origins,
56-day bounded history ending July 3, a comparison panel and reference/adverse inventory examples
including an explicit unavailable case. These are authored fixture identities, without Rossmann
Store mapping, model execution or empirical performance claims.

The builder writes only a new fixed release-ID directory under ignored `artifacts/public_demo/`,
refuses overwrite and atomically renames the staged two-file directory. The verifier accepts only
exact filenames, canonical duplicate-free finite JSON, exact schemas/counts/identities and a trusted
out-of-band manifest pin. Encoded limits are 5 MiB bundle and 64 KiB manifest before decoding.
Path containment and symlink/Windows reparse checks reject aliases. Intrinsic verification checks
configuration/provenance syntax; deterministic regeneration separately checks current code/environment.
The bounded dependency-version grammar is ASCII. These checks do not prove rights, authorization
or hard memory containment.

No Rossmann-derived rows, canonical run/model identities, raw source hashes, credentials,
authorization records or protected outcomes are packaged. Keep originals and generated bytes ignored.
Synthetic content demonstrates interfaces and arithmetic, without claims of historical forecasts,
calibrated uncertainty, physical demand, real stockouts/savings, service guarantees or readiness
for production.

## Provider and service interfaces

Construction requires `DemoProfile.CONTROLLED_SYNTHETIC`, an independently supplied lowercase
64-character manifest SHA-256 and a trusted repository root. The fixed release directory is
resolved internally. Verification and byte checks happen once; a recursively immutable snapshot
and bounded indexes serve queries without filesystem reads. Missing/invalid/tampered/aliased/extra
files fail closed with sanitized typed errors; there is no discovery, regeneration or fallback.

`DemoServices` exposes `catalog`, `sales_history`, `forecast_issuance`, `forecast_uncertainty`,
`model_comparison` and `inventory_comparison`. Reuse existing typed request DTOs, while synthetic
result DTOs carry explicit synthetic provenance rather than false canonical phase/run provenance.
Values, order, zeros, sparse keys, nulls, reasons and declarations remain saved, without service-side
fitting, selection, simulation or arithmetic.

| Query | Fixed supported scope |
|---|---|
| History | Stores 101/202/303, May 9–July 3, at most 56 inclusive calendar days |
| Issuance | Three saved origins, exact H1–H14 paths, raw/operational distinction, `model_execution=none` |
| Uncertainty | `(demo_fit_a, 2015-06-05)` or `(demo_fit_b, 2015-06-19)`; saved daily/cumulative availability |
| Comparison | Fixed candidate/population/window/scope/metric/horizon/Store dimensions, at most 500 rows |
| Inventory | Two fixed cases; Store filter affects policy detail only, while case aggregates retain all-Store denominators |

## API and dashboard contracts

`create_demo_app(profile=..., expected_manifest_sha256=..., repository_root=...)` in
`app/demo_api.py` is an explicit factory, without a default public runtime. It exposes the same
seven GET route paths as the canonical API, with strict query allowlists, duplicate rejection,
bounded requests/responses, no GET body and sanitized JSON. Invalid queries map to 422;
unavailable/invalid releases map to 503. `/health` means process liveness only. Success responses
carry the synthetic evidence label, data and provenance. Existing canonical defaults stay intact.

The separate `demo_streamlit_app.py` calls verified Python services directly. Configure locally:

```powershell
$env:ROSSMANN_DEMO_PROFILE = "controlled_synthetic_demo"
$env:ROSSMANN_DEMO_MANIFEST_SHA256 = "<independently supplied lowercase 64-character SHA-256>"
uv run --locked --extra dashboard streamlit run demo_streamlit_app.py
```

Obtain the pin through a trusted process outside the release manifest. These instructions are a
local usage reference, without permission to publish a bundle or start a public listener.

| Screen | Required interpretation |
|---|---|
| Overview & Evidence | Synthetic source declaration, limitations, release identity and per-view availability |
| Historical Sales | Authored fixture arithmetic, three synthetic Stores and bounded dates |
| Forecast Explorer | Raw versus operational paths; saved Fit pairings; unavailable intervals/prefixes visible |
| Model Comparison | Illustrative saved comparison, without empirical model-superiority claims |
| Inventory Comparison | Monetary stock/turnover values, distinct simulated cost proxy, all-Store aggregate scope and unavailable cases |

Every screen retains synthetic labeling and relevant limitations. Health, bundle readiness and
analytical-view availability are separate facts. No source browsing/uploads/downloads, on-demand
training/inference, raw artifacts, protected outcomes or service-result cache is introduced.
